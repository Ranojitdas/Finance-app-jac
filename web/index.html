What It Already Does

Planning

Creates a deterministic check plan per transaction for predictable demos.

Tool Use

Runs user profile, velocity, merchant risk, amount outlier, and location checks.

Memory

Stores prior cases locally and reuses past outcomes in new decisions.

Multi-Step Reasoning

Combines signals into a weighted risk score and chooses final action.

Explainability

Prints plan -> tool calls -> memory context -> decision with reasons.

Hackathon Friendly

No paid API required. Fully local and deterministic with reset mode.

Agent Flow

  1. Plan checks: decide which validations to run based on transaction context.
  2. Call tools: fetch profile, calculate velocity, merchant risk, and anomaly flags.
  3. Read memory: compute prior fraud rate for that user.
  4. Score: convert observations into risk score 0-100.
  5. Decide: ALLOW, ESCALATE, or BLOCK with top reasons.
Each step is logged so judges can clearly see autonomy, tool usage, and rationale.

How To Use

Install once, then run from project root using commands below.

Install (Windows PowerShell)

powershell -ExecutionPolicy Bypass -File scripts/install_windows.ps1

Install (Linux / macOS)

bash scripts/install_unix.sh

Standard Run

python src/app.py

Deterministic Demo (recommended)

python src/app.py --reset-memory

Windows fallback (if python is not in PATH)

py src/app.py --reset-memory

Run with venv Python (best for judges)

.venv/bin/python src/app.py --reset-memory (Linux/macOS) | .\\.venv\\Scripts\\python.exe src/app.py --reset-memory (Windows)

Tip: Use reset mode before recording your 3-minute demo for stable outputs.

Output appears in terminal with full investigation traces per scenario.

Judge tip: run from project root so relative data and memory paths resolve correctly.

FAQ

Do I need external APIs to run this?

No. The current project is fully local and works without external APIs.

Is Jac included?

Yes. Jac logic is in jac/payguard_agent.jac. Python currently runs the local demo path. You can wire Jaseci runtime for Jac-primary execution in final submission.

Can I host this page quickly?

Yes. Run a local static server and open web/index.html in your browser.
